This web application must be run on port 8081. The full launch path is http://localhost:8081/login.
The project allows you to save multiple images of fish. Roles are divided between admin and user.
Technology stack
Backend: Java 17+, Spring Boot.
Database: MySQL (launched via Docker).
Frontend: Thymeleaf (HTML templates).
Testing: JUnit 5 and Mockito for unit testing.
Architecture: Spring MVC
